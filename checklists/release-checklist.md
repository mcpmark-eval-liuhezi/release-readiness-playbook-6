# Release Checklist

- [ ] Release date and window agreed with product and stakeholders
- [ ] Release sign-off from engineering lead, product owner, and support lead
- [ ] Customer-facing release notes drafted and approved
- [ ] Metrics dashboard and error-rate baselines current for the release window
- [ ] Rollback plan documented and rollback owner identified
- [ ] Monitoring and alerting confirmed for the release window
- [ ] Customer comms (status page, release notes, support queue) prepared
- [ ] Apply and verify the release in staging -> canary -> production
- [ ] Post-release health check: error rates, latency, and customer tickets
- [ ] Release retrospective notes captured
